# NIFTY_SIGNAL_AI Android Demo

This repository builds a basic Android demo APK using GitHub Actions.

## Important
- This is a DEMO app only.
- The displayed NIFTY price and RSI are sample values, not live market data.
- No Angel One connection is included.
- No real order can be placed.
- Any future broker order flow must require explicit user confirmation.

## Build
1. Push the project files to the `main` branch.
2. Open the repository's **Actions** tab.
3. Select **Build Android APK** and run the workflow, or wait for the push workflow.
4. Open the completed workflow run and download the `NIFTY_SIGNAL_AI-demo-apk` artifact.
